How Flotilla works

LLM "admirals" command fleets of deterministic ships. The models never steer a ship directly — they issue standing orders at fixed decision points, and the physics of getting those orders to ships is part of the game.

…and around the whole loop: after each game of a series, every admiral studies its own record and writes a strategy memo to its future self. By default (memo_history) every past game's memo carries forward — game-numbered — into every plan, in-game prompt, and debrief, so a grudge from game 1 still shapes game 4; memo_history=false restores latest-memo-only. A slow or broken model never crashes a game — its fleet just sails on under its last orders, and a real model-API outage auto-pauses the run and probes it back to life rather than burning games.

Combat, in one minute

Ships fight at adjacent cells; every ship fires once per volley ticks for guns×2 − armor damage (min 1) — even a 1-gun trader is a combatant. The volley cooldown is per-ship, so ships don't fire in lockstep. A ship shoots the nearest enemy ship in preference to a flagship — only the assault role targets a flagship first (for guns×2 − 3). A flagship's battery fires proactively (not just in reply) every volley ticks on the nearest flag_targets (default 4) hostile ships anywhere inside its command circle (radius harbor_r) for 10 − armor each — the whole circle is a kill zone. Repairs are yard works, not free: with a shipyard slot they cost treasury and hold a dock (only shipyard_slots=0 gives the old free trickle). Hull = 20 + hull-stat×10. A ship sinks at 0 hull — a laden ship's cargo becomes a wreck where she went down, ready to salvage. Kills score points (kill_score / flag_kill_score), and destroying a flagship eliminates its entire fleet. Role-autopilot ships obey their aggression ladder (0 flee · 1 return fire · 2 engage if stronger · 3 engage anything); conn-programmed ships follow their code. Teammates never damage each other. Every admiral receives a combat report each window. Exact numbers per match: the ⓘ hovers in 🧭 Chart a Course, or the replay's ⚙ Settings tab.

Using this dashboard

⛵ Games (spoiler-free, the home tab) — one row per series or standalone match. Double-click a name to rename it (saved on the server; renames also name your downloads). The 🔍 box filters rows as you type, column headers sort on click, and live runs show a red ✖ Cancel in place of delete (confirmed first; finished games are kept). ▶ Watch opens the spoiler-free player in a new tab; ⬇ builds a single self-contained HTML file you can send to anyone — it works offline, no server needed. 🌐 (when publishing is configured) uploads that same file to a public bucket and hands you a link anyone can open in a browser — no login, no download. 📦 Archive hides a series from the list without touching its data — tick show archived at the top right to see archived series (dimmed) and 📤 Unarchive them. 🗑 deletes a series from the library after a confirmation — that one is permanent.
Games inside a series — click a series row to unfold its game list: each finished game gets its own ▶ Watch and ⬇, and the game being played right now gets a 🔴 Live button. Winners and scores stay hidden until you click reveal — the whole view is spoiler-free by default.
🏆 Tournaments — brackets and leaderboards. Results stay hidden until you hit Reveal, so you can watch the games unspoiled first.
🧭 Chart a Course — every knob that can affect a game, generated from the same schema the engine runs on (the ⓘ hover text is byte-identical to what an agent reads in config-schema.json). Pick a model per player tile, optionally override its settings or give it an operator prompt (saved prompts live on the server), and ⛵ Set sail — runs execute right here and land in the library game by game as they finish.
The player page — ▶ Play, scrub, speed. Right side: Fleets (live scores + each admiral's latest thinking), Admirals (decisions + spend), Parley (the diplomacy feed), Memos (what each model told its future self), Stats (8 charts — score, ships, income rate, treasury, parley, tokens, latency, cost), ⚙ Settings (this exact match's full configuration + how to reproduce it). Click any ship or island to inspect it — ships show what they're trying to do and why. The 👁 selector watches through one admiral's fog of war: you see only what that fleet saw.
Watching a live series — the ⛵ Games row shows a red 🔴 Live button while a run is under way; it drops you on the game being played right now, with a game X of Y header. ⏮/⏭ step between games; the ⏭ button turns red "(Live)" when the next game is the one playing live. If a game finishes while you watch, you stay on it and finish at your own pace — the next games queue up (⏭) rather than yanking you forward.
🖥 Server — the inference-provider ladder. Add a provider key (it is verified and its models auto-discovered + mapped to the admiral ids on the spot), reorder or disable rungs, and set the fallback + canary thresholds. Keys live 0600 in the library, never in git and never returned to the page. See docs/PROVIDERS.md in the repo for the ladder rules.

FAQ

Is this real time? Two pacing modes. By default it's lockstep: the sim pauses at every decision window while the models think, then simulates ~10 seconds of game time near-instantly. With catch-up pipelining on (pipeline_depth > 0) the sim never stops — a fast admiral decides every window, a slow one misses windows and rejoins with a catch-up briefing when its reply lands. Either way, replays play back smoothly regardless of how long any model took.
Do the models see everything? No. Each admiral gets only what its ships have seen (fog of war), a contact plot with last-known enemy positions, and its own believed island stocks. Watch with the 👁 POV selector to see exactly what an admiral saw.
Can models talk to each other? Yes — parley (configurable, on by default). Messages are delivered next window and treated as untrusted: models may lie, bluff, or betray. The game does not enforce deals — but every message is on the record, and the full transcript stays in each model's memory.
Why did a fleet just sit there? Its ships only learn new orders inside the harbor circle or by signal flag. Command latency is a game mechanic, and the signal-flag rules vary by match settings.
Is a game reproducible? A recorded game is: the engine is deterministic (seeded, integer math), so given the same seed and the same admiral decisions it replays byte-for-byte — the ⚙ Settings tab shows the config + seed. That reproduces the match you're watching. Starting a new run from the same seed is different: the live LLMs won't make the identical calls, so the game plays out its own way. The determinism is in the replay, not in the admirals.
What does a game cost? Each replay's Admirals panel shows tokens and dollars per model — scripted-bot games are free; LLM games range from cents (small open models) to a few dollars (frontier models).
Can my agent drive this? Yes — everything the GUI does is documented JSON: config-schema.json, CONFIG.md, and the /api endpoints listed in the server docstring. Agent-first is a design rule here.

Inference providers & keys

The provider ladder, first preference to last. Admirals run on the top enabled rung that serves their model; a 429, a run of timeouts, or repeated 5xx errors drops that model one rung, and a canary probe every few minutes climbs it back up when the higher rung recovers. Keys live in a 0600 file on the server, never in git; only the last characters are ever shown here.
